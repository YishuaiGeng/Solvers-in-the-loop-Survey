# Data

- [papers.csv](papers.csv) / [papers.json](papers.json): one row per included study, with the selected citation report and existing role annotations.
- [schema.md](schema.md): field definitions, missing-value rules, and link provenance.
- [snapshot.json](snapshot.json): dates, counts, and source fingerprints for this release.
- [taxonomy-methods.json](taxonomy-methods.json): representative method placements from the manuscript taxonomy.
- [changes.csv](changes.csv): append-only record of public changes after the initial import.

Browse the [literature catalogue](../papers/README.md) for readable views. The first import is recorded as a release-level event in [CHANGELOG.md](../CHANGELOG.md); the change table starts empty because no subsequent record corrections have been published.
