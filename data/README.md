# Companion data

| Download | Contents |
| --- | --- |
| [papers.csv](papers.csv) / [papers.json](papers.json) | One record per included study, with its selected report, source link, and role annotations |
| [taxonomy-methods.json](taxonomy-methods.json) | Representative method placements matching the current manuscript taxonomy |
| [snapshot.json](snapshot.json) | Release version, scope, counts, and source fingerprints |
| [schema.md](schema.md) | Field definitions, identity conventions, and missing-value rules |
| [changes.csv](changes.csv) | Additions and corrections to released records |

For readable views, use the [classified paper list](../papers/README.md) or the [full literature catalogue](../papers/catalogue.md). For analytical units and cohort coverage, see [analysis](../analysis/README.md).
